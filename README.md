## ✨ Interactive Features Included

1. **80,000 Sq. Ft. Sports Operating System (5 Pillars Explorer)**  
   - Interactive tabbed showcase for **SPACE** (80k Sq.Ft.), **MANAGEMENT** (ILESEUM across 126+ clubs), **PROGRAMS** (Coaching & leagues), **PARTNERSHIPS** (Global academy expertise), and **PROGRESSION** (Measurable health journeys).

2. **Interactive Master Plan & 11-Tower Canvas Explorer**  
   - Dynamic HTML5 Canvas rendering of the 11 residential towers:
     - **Phase 1 / Premium Wings**: Towers A1 & B1 (`2B + 1G + 2P + 1A + 33F`)
     - **Luxury Wings**: Towers A2, A3, B2, B3, C1, C2, D1, D2, D3 (`2B + 1G + 2P + 34F`)
   - Hover and click on towers and sports zones (Football turf, tennis courts, padel, infinity pool, lagoon, forest bathing temple) for instant details.
   - Filter 30+ amenities across **Outdoor Sports**, **Club Ileseum Indoor**, **Pauses of Indulgence**, and **Spiritual & Nature**.

4. **Architectural & Landscape Sanctuaries (Visual Gallery & Lightbox)**  
   - Comprehensive interactive image showcase featuring 9 authentic renderings from the official brochure.
   - Filter by **Towers & Facade**, **Club Ileseum & Sports**, **Zen & Forest Sanctuaries**, and **Luxury Interiors**.
   - Includes a responsive, fullscreen Lightbox modal for high-resolution inspection.

5. **2, 3, & 4 BHK Residences, Comparison Table & SVG Layout Viewer**  
   - Explore **2 BHK Luxury (785-840 Sq.Ft.)**, **3 BHK Premium (1080-1150 Sq.Ft.)**, **3 BHK Grand Corner Suite (1260-1340 Sq.Ft.)**, and **4 BHK Sky Residence & Penthouse (1680-1890 Sq.Ft.)**.
   - **Interactive Side-by-Side Comparison Modal**: Compare carpet areas, balcony sizes, slab heights, elevators, bathrooms, parking allocations, and pricing across all 4 configurations.

6. **The 4 Rhythms of Life (Persona Showcase)**  
   - Dedicated lifestyle cards for **The Working Achiever**, **The Ambitious Parent**, **The Comeback Human**, and **The Community Seeker** with tailored daily township routines and authentic visual headers.

7. **Pimpri Connectivity Map & Distance Explorer**  
   - Filter key Pimpri destinations across **Education**, **Healthcare**, **Workplaces & Hubs**, and **Transit & Connectivity**.
   - Features an interactive dark-themed Canvas Map highlighting Pune Metro Line 1 (PCMC Station - 2.4 km), Kohinoor World Towers (2.0 km), Aditya Birla Hospital (4.1 km), and Hinjewadi IT Park (9.9 km).

   - Live sliders for property value, down payment percentage, loan tenure, and interest rate.
   - Automatically computes monthly EMI, expected 5-year capital appreciation in Pimpri, and estimated rental yield.

9. **Salient Specifications & Global Brand Partner Ticker**

## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or start a simple local development server:

### Option 1: Open Directly in Browser
Double-click `index.html` or open it using Chrome, Safari, Firefox, or Edge:
```bash
open index.html
```

### Option 2: Local Static Server (Python / Node / VS Code Live Server)
```bash
# Using Python
python3 -m http.server 8000

# Using Node (npx serve)
npx serve .
```
Then visit `http://localhost:8000` in your browser.
